# edt-ir - ورکر کلادفلر تنظیم‌شده برای ایران

یک فایل `_worker.js`، بدون مراحل بیلد. اتصال VLESS / Trojan / Shadowsocks را در لبه‌ی کلادفلر
تمام می‌کند و ترافیک را از طریق یک relay (proxyIP) به بیرون می‌فرستد. همه‌چیزش بر اساس رفتار
واقعی خط اینترنت ایران در شهریور ۱۴۰۵ تنظیم شده: DNS دروغ می‌گوید، پورت‌های غیراستاندارد reset
می‌شوند، و چیزی که فیلتر خوانده می‌شود SNI روشن است.

* بدون سرور میانی، بدون دامنه، بدون هزینه: روی پلن رایگان کلادفلر و آدرس `*.workers.dev`.
* لازم: یک حساب کلادفلر و یک حساب گیت‌هاب.
* کل ریپو انگلیسی است و CI در صورت دیدن هر کاراکتر چینی در فایل‌های تحت ترک، build را رد می‌کند.

مجوز GNU GPL-2.0، به فایل `LICENSE` مراجعه کنید.

## اندازه‌گیری روی خط ایران (2026-09-20، بدون پروکسی، `curl` 8.19 ویندوز)

| آزمون | نتیجه | معنا |
| --- | --- | --- |
| `*.workers.dev` با ریزالور ISP | هیچ پاسخی نمی‌آید | DNS مسموم است؛ کلاینتی که نام نود را resolve کند هرگز نمی‌رسد |
| TLS با یک IP کلادفلر و SNI برابر `*.workers.dev` | دست‌دهی TLS کامل شد، HTTP 403 برای نامی که ورکر ندارد | خودِ SNI رست نمی‌شود - رسیدن به لبه با IP کار می‌کند |
| SNI = `www.cloudflare.com` با `Host: <name>.workers.dev` | پاسخ از همان هندلر workers.dev | کلادفلر با Host مسیر می‌زند، پس SNI روشن می‌تواند یک نام بی‌خطر باشد |
| `https://speed.cloudflare.com`، `github.com`، `www.google.com` | HTTP 200 | خط سالم است؛ این هدف‌گیری است نه قطعی |
| `dns.alidns.com/dns-query` | وسط TLS قطع می‌شود | همان bootstrap که برای ECH پیشنهاد می‌شد اینجا مرده است |
| `cloudflare-dns.com`، `dns.google` | connection reset | DoH مسدود است |
| `mozilla.cloudflare-dns.com`، `quad9`، `dns.sb`، `opendns` | پاسخ نمی‌دهند | DoH مسدود است |
| `*.pages.dev`، `*.eu.org` | به یک sinkhole در `10.10.34.x` می‌روند | راه‌حل‌های دامنه‌رایگان هم مسموم‌اند |
| `proxyip.cmliussss.net`، `fra./sin.tp1.090227.xyz` | TLS قطع شد | رله‌های اهدایی می‌میرند؛ `tp1` از استخر حذف شد |

از این جدول چهار قانون بیرون می‌آید که تمام پیش‌فرض‌های زیر از آن ساخته شده: هیچ‌وقت نگذارید
کلاینت چیزی resolve کند، هیچ‌وقت به یک lookup DNS وابسته نباشید، روی پورت 443 بمانید،
و ابزار تشخیص داشته باشید چون رله‌ها فاسد می‌شوند.

## این بیلد چه می‌کند

| بخش | رفتار |
| --- | --- |
| آدرس نود | یک IPv4 واقعی کلادفلر روی **443** - پس مسموم بودن DNS بی‌اثر می‌شود |
| `host` نود | همان هوست‌نیم `*.workers.dev` شما؛ کلادفلر با این مسیر می‌زند |
| `sni` نود | پیش‌فرض `www.cloudflare.com` (فیلد **Outer SNI**)؛ گواهی‌ای که لبه می‌فرستد با همین نام معتبر است، پس verify هم لازم ندارد |
| egress بدون `PROXYIP` | مقدار پیش‌فرضِ colo به‌علاوه‌ی `publicProxyPool`، قاطی و مسابقه‌ای؛ fallback مستقیم روشن |
| egress با `PROXYIP` | کل لیست شما dedup، قاطی و مسابقه‌ای؛ طبق خواسته fallback خاموش |
| خروجی سابسکریپشن | برای هر نوع کلاینت محلی تولید می‌شود؛ چون APIهای مبدل عمومی مرده‌اند، به‌صورت پیش‌فرض هیچ سرویس بیرونی صدا زده نمی‌شود |
| تشخیص | `/admin/pool` هر نامزد egress و resolver مربوط به ECH را **از لبه** تست می‌کند و JSON با زمان پاس‌شدن می‌دهد |
| پنل ادمین | داخل خود ورکر سرو می‌شود (`/login` و `/admin`)؛ هیچ چیز از صفحه‌ی شخص ثالث بارگذاری نمی‌شود |
| زبان | نام متغیرها، کامنت‌ها، رشته‌ها و کلیدهای config همگی انگلیسی |

## دیپلوی

1. این ریپو روی حساب گیت‌هاب شماست.
2. داشبورد کلادفلر -> **Workers & Pages** -> **Create** -> **Deploy from Git**. اگر اتصال گیت‌هاب
   نیست، از **Settings -> Git integration** سطح حساب اضافه کنید و فقط دسترسی همین ریپو را بدهید.
3. همین ریپو را انتخاب کنید، production name = `edt-ir`، بقیه پیش‌فرض - `wrangler.toml` مقدار
   `main` را به `_worker.js` نشان می‌دهد.
4. ورکر -> **Settings -> Variables and Secrets**:

   | متغیر | مقدار | توضیح |
   | --- | --- | --- |
   | `ADMIN` | رمز شما | secret؛ بدون آن هیچ سرویسی بالا نمی‌آید |
   | `KEY` | یک رشته‌ی تصادفی | secret؛ در ساخت UUID اثر دارد و لینک سریع `/<KEY>` را فعال می‌کند |
   | `UUID` | یک UUID نسخه‌ی ۴ | اختیاری؛ اگر نگذاریدش، از `ADMIN` و `KEY` ساخته می‌شود |
   | `PROXY_CONCURRENT_DIAL` | `3` | چند نامزد egress هم‌زمان dial می‌شود |
   | `PRELOAD_RACE_DIAL` | `1` | آدرس مقصد از قبل resolve و مسابقه داده می‌شود |
   | `SNI` | اختیاری | جایگزین Outer SNI؛ خالی بگذارید تا نام workers.dev دوباره در SNI روشن برود |
   | `CFPORT` | اختیاری | پورت نود، پیش‌فرض `443` |

5. **Settings -> Bindings**: یک KV namespace با binding name برابر `KV` اضافه کنید. بدون آن پنل،
   لاگ رویدادها و استخر IP محلی از کار می‌افتد.
6. هر کامیت روی `main` خودش خودکار دیپلوی می‌شود.

اگر از بیلد قدیمی `config.json` در KV مانده، یک بار `/admin` را باز کنید و **Reset defaults** را
بزنید - کلیدهای قدیمی چینی بودند و الان نادیده گرفته می‌شوند.

## تنظیماتی که باید بگذارید

نشانی `https://<your-worker>.workers.dev/admin` را باز کنید، با مقدار `ADMIN` وارد شوید:

| فیلد | مقدار | چرا |
| --- | --- | --- |
| Outer SNI | `www.cloudflare.com` | تنها چیزی است که فیلتر می‌خواند، پس نباید نام شما باشد |
| Protocol / Transport | `vless` / `ws` | مطمئن‌ترین مسیر روی `workers.dev` |
| uTLS fingerprint | `chrome` | مثل دست‌دهی مرورگر واقعی |
| ClientHello fragmentation | `Shadowrocket` یا `Happ` | handshake را تکه‌تکه می‌کند؛ روی خط پر‌افت MCI/Irancell اثر دارد، هرچند DPI می‌تواند دوباره جمعش کند |
| Node port | `443` | بقیه‌ی پورت‌های کلادفلر روی خط ایران reset می‌شوند |
| Refresh interval (hours) | `3` | رنج‌ها و رله‌ها مدام عوض می‌شوند |
| Use ECH | **خاموش** | توضیحش پایین‌تر آمده |
| Skip certificate verify | خاموش | لازم نیست؛ لبه گواهی معتبرِ همان Outer SNI را می‌دهد |

**در مورد ECH صادق باشیم.** کلید `ECH` فقط یک راهنمای `&ech=<inner SNI>+<DoH URL>` به انتهای لینک
اضافه می‌کند. تا وقتی DoH قابل‌دسترسی نباشد که `ECHConfigList` واقعی بگیرد، هیچ handshake با ECH
انجام نمی‌شود و SNI بیرونی همان‌طور روشن می‌ماند - و همه‌ی resolverهایی که این پروژه قبلاً پیشنهاد
می‌کرد روی خط ایران مسدودند (جدول بالا). خاموشش بگذارید و از فیلد Outer SNI استفاده کنید. ECH
واقعی هم شدنی است، اگر `ECHConfigList` را از پیش داخل کلاینت بگذارید (sing-box با `tls.ech`، بدون
نیاز به DoH)؛ ولی این تنظیم کلاینت است، نه چیزی که ورکر بتواند از طرف شما جعل کند.

## خواندن سابسکریپشن وقتی DNS مسموم است

خودِ آدرس سابسکریپشن روی `*.workers.dev` است و ریزالور شما جوابش را نمی‌دهد. سه راه، به ترتیب
اولویت:

1. **لینک نودها را Import کنید، نه سابسکریپشن را.** هر لینک یک IP روشن دارد، پس وقتی وارد کلاینت
   شد دیگر هیچ DNS لازم ندارد. پنل لینک‌ها را نشان می‌دهد؛ کپی و Paste کنید.
2. **نام را در hosts فایل ویندوز قفل کنید** روی همان سیستمی که پنل را باز می‌کند (با اختیارات
   Administrator):
   `Add-Content -Path C:\Windows\System32\drivers\etc\hosts -Value "104.16.132.229  <your-worker>.workers.dev"`
3. **کلاینتی که با remote DNS خودش resolve می‌کند** (sing-box یا NekoBox با یک DoH که خودتان
   دسترس‌بودنش را تست کرده‌اید) - با توجه به جدول بالا، روی این حساب نکنید.

## استخر عمومی proxyIP

انتهای بالای `_worker.js`:

```
const publicProxyPool = ['proxyip.cmliussss.net'];
```

این‌ها رله‌های اهدایی‌اند، زیرساخت شما نیستند، و ضعیف‌ترین حلقه‌ی این طرح‌اند: وقتی بمیرند،
سابسکریپشن import و متصل می‌شود ولی چیزی از آن بیرون نمی‌آید. قبل از اینکه کلاینت را متهم کنید
`/admin/pool` را باز کنید؛ هر نامزد را از لبه‌ی کلادفلر dial می‌کند و `reachable` و زمان را
می‌نویسد. راه‌حل پایدار egress شخصی است: یک proxyIP اختصاصی، VPS یک آشنا با SOCKS/HTTP، یا متغیر
`PROXYIP` با لیست جدا‌شده‌ی کاما.

## عیب‌یابی

1. نود وصل می‌شود ولی صفحه‌ای باز نمی‌شود: در `/admin/pool` ببینید هیچ هدفی `reachable: true` دارد؟
2. همان دستگاه و همان شبکه، آدرس `https://speed.cloudflare.com/__down?bytes=10` را باز کنید؛ اگر
   آن هم نشد مشکل ISP است نه ورکر.
3. ریشه‌ی آدرس ورکر بدون رمز، صفحه‌ی "No admin password configured" را نشان می‌دهد - یعنی کد
   دیپلوی و زنده است.
4. `/admin` بعد از رمز درست به `/login` برمی‌گردد: user agent بین دو درخواست عوض شده، چون کوکی
   به آن گره خورده است.
5. کلاینت خطای handshake یا گواهی غیرمنتظره می‌دهد: فیلد Outer SNI را خالی کنید (یا `SNI=` بگذارید) -
   آن کلاینت جداسازی SNI از Host را قبول نکرده است.
6. پلن رایگان روزی ۱۰۰٬۰۰۰ درخواست برای کل ورکر دارد و هر اتصال پروکسی یک درخواست است؛ یک خانه‌ی
   پرمصرف تا ظهر تمامش می‌کند.

## توسعه

```
node --check _worker.js     # یک ES module تکی، بدون بیلد
```

workflow **Verify** در گیت‌هاب همین چک را روی هر push می‌گیرد، کاراکتر چینی را رد می‌کند، و اگر
ورکر دوباره به صفحه‌ی ادمین بیرونی وابسته شود build را می‌شکند.
